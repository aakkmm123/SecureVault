COMPILER SETTINGS CHECKLIST
================================================================

[ ] 5. Compiler is configured for C99 (not C++):
     [ ] Options -> Compiler Options -> "Additional options" contains:
           -std=c99 -Wall -Wextra
     [ ] "C++ Compiler" is set to "gcc.exe" (not g++)

[ ] 6. Warning options are enabled:
     [ ] -Wall is set (shows all warnings)
     [ ] -Wextra is set (shows extra warnings)

[ ] 5. Project compiles without errors:
     [ ] Press F11 (Build -> Compile) succeeds
     [ ] "Compiler Output" window shows no errors
     [ ] Only informational messages may appear (these are OK)

================================================================
FUNCTIONALITY CHECKLIST
================================================================

[ ] 6. Registration works:
     [ ] Can register a new user with a unique username
     [ ] Registration rejects usernames that are too short (< 4 chars)
     [ ] Registration rejects usernames that are too long (> 31 chars)
     [ ] Registration rejects usernames with invalid characters
     [ ] Registration warns about weak passwords but allows it
     [ ] Registration rejects duplicate usernames

[ ] 7. Login works:
     [ ] Can log in with correct username and password
     [ ] Login rejects incorrect passwords
     [ ] Failed login attempts are counted
     [ ] Account locks out after 3 failed attempts
     [ ] Lockout message displays correctly

[ ] 8. Login history works:
     [ ] Can log in as an authenticated user
     [ ] Can view login history (own history)
     [ ] History shows timestamp, username, and event type
     [ ] History records both successful and failed logins

[ ] 9. Security logs work:
     [ ] Can view security logs as administrator
     [ ] Logs show timestamps and event descriptions
     [ ] Events include registration, login, password changes, deletions

[ ] 10. Password change works:
      [ ] Can change password after verifying current password
      [ ] Changing password with wrong current password fails
      [ ] New password strength is checked

[ ] 11. Account deletion works:
      [ ] Can delete an account with confirmation
      [ ] Account is removed from users.txt
      [ ] Lockout state is reset for deleted account
